# Word Search

Finds words in a grid of given dimensions, for anyone.

Made as a project for a class at Michigan State University. Allows automatic word-search solving.

## Prerequisites
Unix Terminal or other C++ compiler required.

## Installation

Get your development environment running by executing these steps:

```bash
Open Terminal
On Mac: cmd + space to open spotlight and type terminal, press enter to open
On Windows: windows key + R, type wt and enter
```

## Usage

How to execute program:

```bash
Once terminal is open...
Navigate to where folder is stored using the "cd" command, ex) "cd WordSearch".
Once in the folder WordSearch, compile using "g++ word_search.cpp" and any other flags you'd like.
Run the file using the command "./a.out" to create and executable.
Run the example input using the command "./a.out <example_in.txt".
```
